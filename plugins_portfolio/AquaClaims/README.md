## ✨ Key Features

- 🚩 **Chunk-Based Instant Claims (`/claim`):** Claim land with a single command or visual boundary inspection.
- 🤝 **Trust Delegation (`/trust`):** Share building and chest access with trusted friends across all your properties.
- 🛡️ **Anti-Grief Protection:** Automatically blocks unauthorized block breaking, placing, chest looting, explosions, and griefing.
- ✨ **Particle Border Walls:** Outlines claims with visible particle perimeters to clearly mark wilderness vs protected territory.

---

## 💻 Commands & Permissions

| Command | Permission | Description |
|---|---|---|
| `/claim` | `aquaclaims.user` | Claim your current chunk |
| `/unclaim` | `aquaclaims.user` | Abandon owned chunk claim |
| `/trust <player>` | `aquaclaims.user` | Grant build trust in all claims |
| `/untrust <player>` | `aquaclaims.user` | Revoke trust |
