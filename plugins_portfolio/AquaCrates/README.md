## ✨ Key Features

- 🌀 **3D Particle Spiral Opening:** Dynamic helical particle animations that build suspense before reward unveiling.
- 🎆 **Fireworks Celebration:** Climax firework bursts and victory sound effects on rare unboxings.
- 💎 **1.21.1/1.21.4 Component Support:** Preserves custom item lore, enchantments, and custom model data.
- 🎯 **Pity System:** Guarantee rare drops after a set number of crate attempts.
