**AquaStaff** equips server administrators and moderators with a high-speed inspection kit: instant silent vanish, screen freeze lockdown with blindfold, live target inventory viewing, and flight mode. Universal support across Paper 1.20.x through **1.21.11 (Mounts of Mayhem)**.

## ✨ Key Features

- 🕵️ **1-Click Staff Mode (`/staff`):** Toggles flight speed, auto-vanish, and moderation tools.
- 👻 **Total Silent Vanish (`/vanish`):** Complete invisibility from player tab lists and entity rendering.
- 🧊 **Suspect Freeze Lockdown (`/freeze`):** Disables player movement and commands while displaying on-screen investigation instructions.
- 🎒 **Live Inventory Inspector (`/invsee`):** Directly view and interact with online player inventories in real time.

---

## 💻 Commands & Permissions

| Command | Permission | Description |
|---|---|---|
| `/staff` | `aquastaff.mod` | Toggle complete staff moderation mode |
| `/vanish` | `aquastaff.mod` | Toggle silent administrator invisibility |
| `/freeze <player>` | `aquastaff.mod` | Freeze/unfreeze a suspected cheater |
| `/invsee <player>` | `aquastaff.mod` | Live inspect target player inventory |
