## ✨ Key Features

- 💀 **Procedural Mob Waves:** Spawns escalating difficulty waves with custom loot modifiers.
- 👹 **Custom Boss Encounters:** Integrated colored BossBars, phase shifts, and arena music.
- 🏆 **Group Raid Sessions:** Join queues with party member tracking and shared rewards.

---

## 💻 Commands & Permissions

| Command | Permission | Description |
|---|---|---|
| `/dungeon join` | `aquadungeons.user` | Join active raid session |
| `/dungeon leave` | `aquadungeons.user` | Leave raid instance |
| `/dungeon startwave` | `aquadungeons.admin` | Force-start combat wave |
