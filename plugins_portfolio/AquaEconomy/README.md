**AquaEconomy** is a zero-lag financial foundation built for high-scale Minecraft networks. It replaces outdated economy plugins with sub-millisecond wallet transactions, player banking with interest rates, and Vault compatibility. Universal support across Paper 1.20.x through **1.21.11 (Mounts of Mayhem)**.

## ✨ Key Features

- ⚡ **Zero-Lag In-Memory Engine:** Handles thousands of concurrent transactions with periodic safe disk flushing.
- 💳 **Dual-Layer Accounts:** Physical player wallet + secure banking storage with daily interest.
- 🤝 **Player-to-Player Payments:** Instant peer transfers with audio cues and transaction receipts.
- 🛠️ **Administrative Master Controls:** `/eco give`, `/eco take`, `/eco set` for server owners.
- 🔌 **Vault API Ready:** Acts as a primary economy provider for shops, auctions, and claims.

---

## 💻 Commands & Permissions

| Command | Permission | Description |
|---|---|---|
| `/balance [player]` | `aquaeconomy.user` | Check current wallet and bank balance |
| `/pay <player> <amount>` | `aquaeconomy.user` | Transfer funds to another player |
| `/bank` | `aquaeconomy.user` | Open the banking interface |
| `/eco <give\|take\|set> <player> <amount>` | `aquaeconomy.admin` | Admin financial management |
