**AquaSkills** is a lightweight, zero-lag alternative to legacy RPG skill systems (such as mcMMO). It introduces modern leveling, double-drop proc mechanics, and action bar XP notifications for Paper 1.20.x – 1.21.11.

## ✨ Key Features

- ⛏️ **Mining & Combat Mastery:** Earn XP from every ore extracted and monster defeated.
- 💎 **Passive Double-Drop Scaling:** Level progression directly unlocks percentage chances for doubled resource drops.
- 🔔 **Action Bar HUD Feedback:** Non-intrusive action bar alerts on every XP gain.
- 🏆 **Level-Up Celebrations:** Full title cards and victory sounds on milestone level-ups.

## 💻 Commands & Permissions

| Command | Permission | Description |
|---|---|---|
| `/skills` | `aquaskills.user` | View skill levels and progress |
| `/aquaskills` | `aquaskills.admin` | Admin XP manipulation |
